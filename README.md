# Documentazione Project Work NEO-BANK

Per eseguire il software:

1) fare il clone dei seguenti repository in una directory:

- https://github.com/paolovzz/neo-bank-auth
- https://github.com/paolovzz/neo-bank-cliente
- https://github.com/paolovzz/neo-bank-conto-corrente
- https://github.com/paolovzz/neo-bank-ext-system
- https://github.com/paolovzz/neo-bank-carta
- https://github.com/paolovzz/neo-bank-bonifico
- https://github.com/paolovzz/neo-bank-notifica
- https://github.com/paolovzz/neo-bank-gateway
- https://github.com/paolovzz/neo-bank-frontend


2) aggiungere il docker compose presente in questo repo

3) sempre nella cartella contenente i progetti copiare la directory keycloak, con tutto il suo
contenuto, presente in questa repo

4) aggiungere lo starter.sh presente in questo repo

5) eseguire nel terminale, dentro la directory, il comando './starter.sh'
